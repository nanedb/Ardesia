# Blocchi appunti, sezioni e pagine

Ardesia organizza gli appunti come OneNote:

- un **blocco appunti** (un file `.ardesia`) – per esempio uno per classe e materia: «Matematica 3B»;
- dentro, le **sezioni** (colonna di sinistra, ognuna col suo colore) – per esempio «Geometria», «Algebra», «Verifiche»;
- le sezioni possono contenere **sottosezioni**, a qualsiasi profondità;
- ogni sezione contiene **pagine** (seconda colonna), e ogni pagina può avere **sottopagine**, anche queste senza limiti.

Le due colonne si possono **allargare o stringere** trascinando il loro bordo destro, e **nascondere** con il pulsante ☰ in alto a destra (o *Visualizza → Navigazione*), per avere tutto lo schermo per scrivere.

## Sezioni

- **Aggiungi sezione** (in fondo alla colonna) oppure *Inserisci → Nuova sezione* / *Nuova sottosezione*.
- **Clic destro** (o pressione prolungata col dito) su una sezione apre il suo menu:

| Voce | |
|---|---|
| Nuova pagina | Aggiunge una pagina alla sezione |
| Nuova sezione / Nuova sottosezione | Accanto o dentro questa |
| Rinomina | Anche con **F2** |
| Colore della sezione | Scegli fra i colori proposti |
| Sposta su / Sposta giù | Cambia l'ordine |
| Rendi sottosezione della precedente | La mette dentro la sezione che sta sopra |
| Porta al livello superiore | La tira fuori dalla sezione che la contiene |
| Esporta la sezione in PDF… | |
| Elimina la sezione | Chiede conferma; **non si può annullare** |

Un blocco appunti deve avere almeno una sezione.

## Pagine e sottopagine

- **Aggiungi pagina** (in cima alla colonna delle pagine), **Ctrl+N**, oppure *Inserisci → Nuova pagina*, *Nuova sottopagina*, *Duplica pagina*.
- Ogni pagina ha in alto il **titolo** («Titolo della pagina»: scrivici sopra) e la data e l'ora di creazione. Una pagina senza titolo compare nell'elenco come «Pagina senza titolo».
- Le sottopagine si aprono e si chiudono con la freccetta accanto alla pagina che le contiene.
- **Clic destro** su una pagina:

| Voce | |
|---|---|
| Nuova pagina / Nuova sottopagina | |
| Duplica la pagina | Copia la pagina con tutto il contenuto |
| Rinomina | Anche con **F2** |
| Sposta su / Sposta giù | |
| Rendi sottopagina | La mette sotto la pagina che sta sopra |
| Promuovi pagina | La riporta al livello superiore |
| Sposta nella sezione | Sposta la pagina in un'altra sezione |
| Esporta la pagina in PDF… | |
| Elimina la pagina | Chiede conferma; **non si può annullare** |

## Riordinare trascinando

Sezioni e pagine si possono anche **trascinare** con il mouse nell'elenco per cambiarne l'ordine o la posizione.

## Tasti utili nell'elenco

- **F2** – rinomina la sezione o la pagina selezionata (Invio conferma, Esc annulla).
- **Canc** – elimina (con conferma).

## Il salvataggio

Non c'è nulla da salvare a mano: ogni cambiamento (anche un titolo o un colore) si salva da solo dopo un attimo. Vedi [Primo avvio → Il salvataggio automatico](Primo-avvio#il-salvataggio-automatico).
