# Scorciatoie da tastiera

| Tasti | Azione |
|---|---|
| **Ctrl+S** | Salva (di solito non serve: Ardesia salva da sola) |
| **Ctrl+O** | Apri un blocco appunti |
| **Ctrl+N** | Nuova pagina |
| **Ctrl+P** | Esporta in PDF |
| **Ctrl+Z** / **Ctrl+Y** | Annulla / Ripeti |
| **Ctrl+C** / **Ctrl+X** / **Ctrl+V** | Copia / Taglia / Incolla |
| **Ctrl+A** | Seleziona tutto il contenuto della pagina |
| **Canc** | Elimina la selezione |
| **Ctrl+B** / **Ctrl+I** / **Ctrl+U** | Grassetto / Corsivo / Sottolineato (nelle caselle di testo) |
| **Ctrl + rotellina** | Zoom della pagina |
| **Ctrl + +** / **Ctrl + −** / **Ctrl + 0** | Ingrandisci / Riduci / Zoom al 100% |
| **Rotellina** / **Maiusc + rotellina** | Scorre in verticale / in orizzontale |
| **Rotellina** sopra un grafico selezionato | Zoom degli assi del grafico |
| **Maiusc** mentre disegni una forma | Linea a 15°, quadrato, cerchio |
| **F11** | Schermo intero |
| **Esc** | Chiude compasso, forme, Sposta pagina e Inserisci spazio tornando allo strumento di prima; esce dallo schermo intero |
| **F2** (nell'elenco) | Rinomina la sezione o la pagina |
| **Canc** (nell'elenco) | Elimina la sezione o la pagina (con conferma) |
